# Калькулятор электрических цепей (ТОЭ)

Кроссплатформенное Flutter-приложение (**Windows Desktop** и **Android**) для расчёта линейных электрических цепей постоянного (DC) и синусоидального переменного (AC) тока с визуальным редактором схем и пошаговым выводом решения в формулах LaTeX.

## Поддерживаемые методы расчёта

1. **Метод эквивалентных преобразований (свёртывание схемы)** — последовательное, параллельное соединение, преобразование источников $E \leftrightarrow J$, $\Delta \to \text{Y}$ (треугольник–звезда).
2. **Законы Кирхгофа** — автоматическое построение остовного дерева и системы уравнений по 1-му и 2-му законам Кирхгофа.
3. **Метод контурных токов** — расчёт по независимым контурам (с поддержкой ветвей с источниками тока).
4. **Метод узловых потенциалов** — выбор базового узла ($\varphi = 0$) и модифицированный узловой анализ (включая идеальные ветви ЭДС).
5. **Метод наложения (суперпозиции)** — поочерёдное действие каждого источника энергии и суммирование частичных токов.
6. **Метод эквивалентного генератора (Тевенина / Нортона)** — определение $U_{\text{хх}}$, $Z_{\text{экв}}$, $I_{\text{кз}}$ и тока в выбранной целевой ветви.
7. **Комплексный метод (AC)** — расчёт цепей синусоидального тока в комплексной форме с выбором базового алгоритма, построением векторной диаграммы токов и выводом мгновенных значений $i(t)$.

## Возможности

- **Визуальный редактор схемы на сетке**: добавление/перемещение/удаление узлов и ветвей, редактирование $R, L/X_L, C/X_C, E, J$, выбор базового узла и целевой ветви.
- **6 готовых шаблонов ТОЭ** (двухконтурная цепь, смешанное соединение, мост Уитстона, цепь с источником тока, трёхветвевая AC-цепь, параллельный RLC-контур).
- **Гибридный вывод результатов**: компактная сводная таблица токов/напряжений/мощностей, проверка баланса мощностей ($\sum P_{\text{ист}} = \sum P_{\text{потр}}$), наложение токов и потенциалов на схему и кнопка **«Показать подробное решение»** с LaTeX-формулами.
